# Pruebas del asistente CAYCSOL

- Contraseña olvidada: comprobar preguntas guiadas.
- Usuario bloqueado: comprobar orientación sin solicitar claves.
- Código de verificación: comprobar solución progresiva.
- Aplicación no carga: comprobar diagnóstico de conexión.
- Si no se resuelve, ofrecer soporte humano.

No utilizar datos reales de afiliados.
