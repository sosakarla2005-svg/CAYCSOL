# CAYCSOL Digital — prototipo académico

Aplicación web demostrativa de banca digital inspirada en servicios cooperativos. **No es un producto oficial de CAYCSOL**.

## Funciones
- Saldo de demostración inicial: L 10,000.00
- Depósitos, retiros, pagos y transferencias **simulados**
- Comprobantes ficticios e historial temporal
- Ayuda contextual y diseño adaptable a celular

## Uso
Abrir `index.html` en un navegador o publicar el repositorio mediante **Settings → Pages → Deploy from a branch → main / (root)**.

## Cómo se construyó
1. Se creó el repositorio GitHub.
2. Se desarrolló una interfaz HTML con estilos CSS y lógica JavaScript.
3. Se incorporaron validaciones de montos y control de saldo ficticio.
4. Se añadieron historial y comprobantes de demostración.
5. Se preparó la publicación estática en GitHub Pages.

## Seguridad y alcance
- No solicitar ni escribir contraseñas, PIN, números de identidad ni datos bancarios reales.
- No se conecta a sistemas financieros.
- Los movimientos solo existen en memoria del navegador y desaparecen al recargar.
- No usar comprobantes como constancia de pago real.
